# AI Builders 周报 — 2026-09-21

## 🧠 模型发布

- **[Gemini 3.8 Live](https://deepmind.google/blog/introducing-gemini-3-8-live-and-3-8-live-extended-thinking/)** 与 **Gemini 3.8 Live Extended Thinking**（Google，9 月 15 日）面向实时语音对话和 voice agent。Live 支持近实时视觉输入、对话中切换 97 种语言，并可在后台执行工具/API 调用；Extended Thinking 可以边说边做多步推理。两者已开始通过 Gemini API 和 Google AI Studio 推出，企业侧为 private preview。Google 披露 Extended Thinking 在 Speech to Speech Quality Index 得分 82.6、τ-Voice 任务完成率 68.6%。**评价**：本周最值得关注的不是单纯语音质量，而是“不中断对话的后台 agent 执行”开始成为实时模型的产品基线。

- **[DeepSeek-V4.1-Flash](https://www.deepseek.com/en/news/deepseek-v4-1-flash/)**（DeepSeek，9 月 9 日）是新架构家族中最小的模型，552B MoE、输入侧 8B active、输出侧 16B active，原生支持视觉理解；KV cache 需求降到上一代的 1/4 HBM、1/8 SSD。模型已上线 DeepSeek API，旧版 V4-Flash 和 V4-Flash-Vision-Exp 兼容路由到它，9 月 14 日起 V4-Pro 请求也会按 V4.1-Flash 价格路由。**评价**：它把重点从“更大参数”转向不对称架构、cache 成本和吞吐，尤其适合长上下文 agent 服务。
