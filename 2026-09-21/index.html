AI Builders 周报 — 2026-09-21

🧠 模型发布​

  • Gemini 3.8 Live 与 Gemini 3.8 Live Extended Thinking（Google，9 月 15 日）面向实时语音对话和 voice agent。Live 支持近实时视觉输入、对话中切换 97 种语言，并可在后台执行工具/API 调用；Extended Thinking 可以边说边做多步推理。两者已开始通过 Gemini API 和 Google AI Studio 推出，企业侧为 private preview。Google 披露 Extended Thinking 在 Speech to Speech Quality Index 得分 82.6、τ-Voice 任务完成率 68.6%。评价：本周最值得关注的不是单纯语音质量，而是“不中断对话的后台 agent 执行”开始成为实时模型的产品基线。

  • DeepSeek-V4.1-Flash（DeepSeek，9 月 9 日）是新架构家族中最小的模型，552B MoE、输入侧 8B active、输出侧 16B active，原生支持视觉理解；KV cache 需求降到上一代的 1/4 HBM、1/8 SSD。模型已上线 DeepSeek API，旧版 V4-Flash 和 V4-Flash-Vision-Exp 兼容路由到它，9 月 14 日起 V4-Pro 请求也会按 V4.1-Flash 价格路由。评价：它把重点从“更大参数”转向不对称架构、cache 成本和吞吐，尤其适合长上下文 agent 服务。

🔥 新产品发现​

  • Cactus Needle 3 — 8–29MB 的 automation model，目标是在手机、穿戴设备、智能家居、机器人和汽车等小型设备上提供 tool calls、structured extraction 与 embeddings。[HN Show HN · 231👍 · 91💬]
  • cloudflare/security-audit-skill — 面向 coding agent 的多阶段安全审计 skill，输出可机器读取、可独立验证的 findings。[GitHub Trending · 2428⭐]
  • trycua/cua — 开源 computer-use driver、跨操作系统 fleet 与 benchmark，用于扩展 computer-use 训练、评估和数据生成。[GitHub Trending · 1018⭐]
  • BuilderIO/agent-native — 构建 agentic app 的 framework，把 agent 行为作为应用交互的一等部分。[GitHub Trending · 98⭐]
  • coder/coder — 为开发者及其 agents 提供安全的开发环境，适合把 agent 执行隔离到可管理的 workspace。[GitHub Trending · 379⭐]
  • vercel-labs/json-render — Generative UI framework，用 JSON 描述界面并交给前端渲染，适合 agent 生成可控 UI。[GitHub Trending · 291⭐]
  • addyosmani/agent-skills — 面向 AI coding agent 的 production-grade engineering skills 集合。[GitHub Trending · 736⭐]
  • supermemoryai/supermemory — 可本地运行的 memory/context engine 与 Memory API，针对 agent 的长期上下文和检索。[GitHub Trending · 169⭐]
  • Tencent/BrowserSkill — 让 agent 使用用户真实、已登录的浏览器，提供 CLI 与 extension，适用于跨 shell 的浏览器自动化。[GitHub Trending · 324⭐]
  • krillinai/OpenCreator — 面向创作者的开源 AI workspace，覆盖视频、图片、语音、avatar、翻译和剪辑，并由 agents 驱动。[GitHub Trending · 263⭐]
  • diffusionstudio/editor — 为 agents 构建的开源视频编辑器，主张“edits become code, code becomes video”。[GitHub Trending · 63⭐]
  • KnockOutEZ/wigolo — local-first 的 search、fetch、crawl 和 research over MCP 工具，不需要 API key，当前为 public beta。[GitHub Trending · 25⭐]

🐦 开发者动态​

  • Aaron Levie（Box CEO）：他认为 personal agent 的最终形态是把任务端到端交给 agent，并要求 agent 能操作现有工具或自带工具、使用 MCP/CLI、可靠导航网站并确认任务完整结束。
  • Nikunj Kothari（FPV Ventures partner）：他分享自己每天约两小时编程、做 side project 和试新 repo 的习惯，理由是 AI 变化太快，不亲手构建就无法理解正在发生什么。
  • Peter Yang（AI tutorials and interviews）：他展示了用 Markdown 文件和 /tastemaker skill 给电影、电视剧和书籍打分，再自动发现新内容的个人推荐工作流，并询问是否开源。
  • Guillermo Rauch（Vercel CEO）：他把最近 AI 浪潮的核心归纳为“大家都在兴奋地构建”，认为开发和交付产品而非仅仅消费 AI，是这轮变化中最积极的部分。
