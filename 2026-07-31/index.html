AI Builders Digest — 2026-07-31

🧠 模型发布​

Gemini Robotics ER 2 — Google 的 embodied reasoning 模型，面向机器人视频理解、进度跟踪、多步任务规划和多机器人协作，可调用 Google Search 及用户自定义函数，并通过 Gemini Live API 做低延迟双向流式编排。可用性: Gemini API、Google AI Studio 公开可用，Gemini Enterprise Agent Platform 私有预览。评价: 重点不是单纯提升 VLM 分数，而是把机器人从“看懂”推进到持续观察、纠错与协作执行。

Inkling-Small — 276B 参数 MoE、12B active，支持 text、image、audio 原生 reasoning，最长 1M tokens context，并在 Terminal-Bench 2.1、HLE 与 IFBench 等任务上以更少 compute 取得接近或超过 Inkling 的表现；HLE 得分 31.6%，SWEBench-Verified 超过 80%。可用性: full weights 开放，支持在 Tinker 上 fine-tuning，并可在 Tinker Playground 进行 text/image/audio chat。评价: 以较小 active 参数换取接近旗舰的 agentic coding 与 reasoning 性能，效率比绝对规模更值得关注。

Grok Voice Think Fast 2.0 — speech-to-speech voice model，AA Speech-to-Speech Quality Index 82.9%，Full Duplex Bench 95.1%，agentic performance 56.5%，Time to First Audio 0.70s；官方称其在 24 种语言转写上较前代提升 1.4 倍，并以约 0.4 倍 reasoning tokens 完成回答。可用性: xAI Voice API，$0.08/分钟；grok-voice-latest 将于 8 月 5 日切换到 2.0。评价: 把语音 agent 的核心竞争点从“能听能说”拉到实时对话节奏、工具调用与全双工交互。

🔥 新产品发现​

  • Distilling DeepSeek into GPT-OSS doesn't transfer censorship — HN 上关于模型蒸馏与 censorship transfer 的研究实验，讨论安全行为是否会随能力一起迁移。[HN 76👍]
  • Claude-account — 在不重复登录的情况下切换 Claude Code 账号，适合多身份开发工作流。[HN 43👍]
  • Claude Code Merge Queue — 面向并行 Claude Code agent 的本地 merge queue，减少多 agent 同时改仓库时的冲突。[HN 41👍]
  • Segue — 用短 handle 保存一个 AI 中的上下文，再在另一个 AI 中加载，解决跨模型迁移工作上下文的问题。[HN 31👍]
  • Supapool — 为每个 coding agent 快速创建独立 Supabase 后端，目标是把 agent 的环境隔离压缩到约 400ms。[HN 27👍]
  • openwork — 基于 opencode 的 Claude Cowork 开源替代方案，面向本地 coding agent 工作流。[GitHub Trending 915⭐]
  • Agent-Reach — 给 AI agent 接入 Twitter、Reddit、YouTube、GitHub、Bilibili、小红书等互联网信息源的 CLI，主打免 API 费用。[GitHub Trending 543⭐]
  • Chrome DevTools MCP — 为 coding agent 提供 Chrome DevTools 能力，把浏览器调试与性能分析纳入 agent 工作流。[GitHub Trending 80⭐]
